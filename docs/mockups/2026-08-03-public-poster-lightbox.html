設計稿：公開報名頁「海報放大檢視」

背景：海報原圖 2505 × 3534 px（R2 直出，後端不壓縮），但頁面左欄只有 526 CSS px 寬， 約 2.4 倍降採樣，印刷用小字被縮到 17px 以下 → 家長覺得「畫質不夠高」。 本次不動原圖也不改版面寬度，只加「點擊放大」讓家長能看到原圖真實解析度。

可以點的地方：把滑鼠移到海報上 → 出現「點擊放大」提示與右下角原有的下載／分享； 點海報本身即開燈箱（Esc 或點深色背景關閉）。右下角控制列可切「改前現況／改後」與標註顯隱。
